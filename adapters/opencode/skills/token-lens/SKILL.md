# Token Lens: аналитика токенов OpenCode

Token Lens измеряет расход токенов локально: без сети, только данные текущей
машины (`~/.opencode/token-lens/`).

## Что использовать

- `token_usage_panel` — markdown-ссылка «📊 Аналитика запроса/ответа» на отчёт
  текущего или последнего хода, краткая сводка и индикатор контекста под ней,
  если включены в Settings.
  Добавляй **всё поле `markdown` в самом конце** финального ответа без изменений,
  сохраняя все строки.
- `read_token_usage` — те же данные в JSON (measured tokens, cost, потребители,
  шаги). Используй для ответов на вопросы про цифры.

## Как читать цифры

- **Measured** — фактические счётчики из assistant-сообщений OpenCode: вход,
  выход, рассуждения и кэш (read/write) отдельно; вход не включает кэш.
  Итог хода — сумма по шагам с дедупликацией по messageID.
- **Cost** — сумма cost шагов, если провайдер её вернул; иначе «недоступно».
- **Потребители** — оценка UTF-8 байт / 3 по аргументам и результатам
  инструментов за ход. Это приближение, не биллинг.
- Нет счётчиков за ход — в отчёте «недоступно», а не 0.

## Отчёты и настройки

- Отчёт хода: стабильный URL вида `http://127.0.0.1:3848/answers/<key>.html`,
  где key = `sessionID_promptMessageID`. Live-страница создаётся в начале хода
  и дополняется счётчиками после завершения.
- All Reports: `http://127.0.0.1:3848/` (список, мульти-удаление).
- Settings: `http://127.0.0.1:3848/settings` (автоудаление старше N дней).
  Переключатель «Краткая сводка токенов после ссылки» (`appendTokenSummary`, по
  умолчанию off) добавляет вход/выход из measured на момент ссылки. Кэш и
  рассуждения в эти два числа не входят. Полный итог, включая финальный текст,
  доступен в отчёте после завершения; без полных счётчиков сводка пропускается.
  Дата в строке «Токены ДД.ММ.ГГГГ ЧЧ:ММ: …» — время снимка отчёта в местном
  часовом поясе; сохраняй её из `markdown`, не подставляй текущее время.
- «Индикатор контекста после ссылки» (`appendContextHeat`, по умолчанию off)
  добавляет строку вида `🔥 Контекст: 71% · скоро новый чат`. Сигнал — вход
  последнего измеренного запроса, включая cache read/write, поделённый на
  `contextWindow` (по умолчанию 200000). Это приблизительная оценка заполнения
  окна, не суммарный расход хода. Без измерения строка пропускается.

## Правила

- Не выдумывай цифры и URL — только данные инструментов и отчётов.
- Не запускай follow-up только ради ссылки или цифр.
- Ход (turn) начинается с prompt-сообщения пользователя; компакция, генерация
  заголовка и transient generate в отчёт хода не входят.
