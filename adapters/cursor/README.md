# Token Lens для Cursor IDE

Локальный анализатор расхода токенов: ссылка «📊 Аналитика запроса/ответа», HTML-отчёты, оценка потребителей инструментов и необязательная панель со строкой состояния. Версия плагина и MCP-сервера — 0.2.0; отдельного IDE-расширения — 0.1.2. Лицензия адаптера — [MIT](LICENSE).

## Установка

Эти команды рассчитаны на **Windows PowerShell**. Нужны Node.js 22+, npm и Cursor с разрешённой загрузкой локальных плагинов. Проверьте `node --version` и `npm --version` в терминале. Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd` вместо `npm` в командах ниже.

### 1. Скопируйте адаптер

Откройте PowerShell **в корне репозитория `token-lens`**, рядом с корневым README:

```powershell
$tokenLensPlugin = Join-Path $env:USERPROFILE '.cursor\plugins\local\cursor-token-lens'
New-Item -ItemType Directory -Path $tokenLensPlugin -Force | Out-Null
Get-ChildItem -LiteralPath '.\adapters\cursor' -Force |
  Where-Object { $_.Name -notin @('node_modules', 'token-lens.vsix') } |
  Copy-Item -Destination $tokenLensPlugin -Recurse -Force
Set-Location -LiteralPath $tokenLensPlugin
npm ci --ignore-scripts
npm test
```

Копируется содержимое адаптера, включая скрытый `.cursor-plugin`. Итоговый путь манифеста — `~/.cursor/plugins/local/cursor-token-lens/.cursor-plugin/plugin.json`; дополнительной вложенной папки `cursor` быть не должно.

### 2. Включите аналитику

Если существует `~/.cursor/mcp.json`, сохраните его копию и убедитесь, что он содержит корректный JSON: текущий установщик при ошибке разбора заменяет конфигурацию пустой. Затем **из папки установленного плагина** выполните:

```powershell
node scripts/enable-default.cjs
```

Установщик:

- добавляет `cursor-token-lens` в пользовательский `~/.cursor/mcp.json`, сохраняя остальные корректные записи;
- записывает глобальное правило `~/.cursor/rules/token-lens-analytics.mdc`, чтобы агент добавлял ссылку без упоминания плагина;
- создаёт `token-lens-server.cmd` в папке автозагрузки Windows и запускает локальный сервер отчётов на `http://127.0.0.1:3847/`.

В результате команды проверьте `serverStatus.ok: true` и путь `startup`. Если вместо пути показана ошибка, автозагрузка не установилась; сервер можно запускать вручную, как описано ниже. Само поле `enabled: true` ещё не подтверждает запуск сервера.

Оставьте MCP **только в пользовательской конфигурации**. Файл `mcp.json.example` в адаптере — пример, переименовывать его в `mcp.json` не нужно: иначе Cursor может подключить MCP дважды.

### 3. Перезагрузите Cursor и проверьте

В Command Palette (`Ctrl+Shift+P`) запустите **Developer: Reload Window** либо полностью перезапустите IDE. В **Customize** проверьте наличие локального `cursor-token-lens`, его hooks, правил и пользовательского MCP-сервера.

Из папки установленного плагина выполните:

```powershell
node scripts/serve.cjs --status
```

Ожидается `running: true`. Откройте [локальную страницу Token Lens](http://127.0.0.1:3847/). В новом чате отправьте короткий запрос и дождитесь завершения ответа. После события `stop` в списке должна появиться HTML-страница; её ссылка открывается в браузере. До первого завершённого хода список пуст. Если Cursor не передал счётчики токенов, отчёт покажет их отсутствие, а не нулевой расход.

Локальные плагины и их обнаружение описаны в [официальной документации Cursor](https://cursor.com/docs/plugins). Корпоративная политика может запрещать локальные плагины. Установленный из marketplace плагин с тем же именем имеет приоритет над локальной копией.

## Необязательное расширение IDE

Для строки состояния и панели внутри Cursor из папки установленного плагина выполните:

```powershell
node scripts/install-extension.cjs
```

Скрипт копирует расширение в `~/.cursor/extensions/` и обновляет локальный индекс расширений. После **Developer: Reload Window** появятся `TokenLens` в строке состояния и команда **Token Lens: Open Panel**. Для просмотра HTML-отчётов это расширение не требуется.

## Управление сервером

Из папки установленного плагина:

```powershell
node scripts/serve.cjs --status
node scripts/serve.cjs --start
node scripts/serve.cjs --restart
node scripts/serve.cjs --stop
```

Также есть команда чата `/token-lens-server`. Сервер автоматически запускается при входе в Windows, событиях Cursor `workspaceOpen`, `sessionStart`, `beforeSubmitPrompt`, активации IDE-расширения и формировании страницы/ссылки ответа. Поэтому `--stop` останавливает текущий процесс; последующее событие может запустить его снова.

Если страница недоступна, выполните `--start` и повторно проверьте `--status`. Если порт 3847 занят другим приложением, освободите его перед запуском. Сервис привязан к `127.0.0.1`.

## Обновление

1. В корне Git-копии выполните `git pull --ff-only` или распакуйте свежий ZIP.
2. Повторите шаги 1–3 установки. Установщик обновит глобальное правило и автозагрузку.
3. Из папки установленного плагина выполните `node scripts/serve.cjs --restart`, чтобы работающий сервер загрузил новую версию.
4. Если устанавливали расширение IDE, повторите `node scripts/install-extension.cjs`, затем **Developer: Reload Window**.

Исходники и зависимости обновляются в папке плагина. Накопленные отчёты находятся отдельно в `~/.cursor/token-lens/`.

## Данные и ограничения

- `beforeSubmitPrompt` сохраняет превью первых 200 символов запроса и его длину; эти данные могут попадать в локальные JSON/HTML-отчёты.
- `postToolUse` оценивает аргументы и результаты инструментов как UTF-8 байт / 3. Это оценка видимого ввода, а не распределение биллинга. Инструкции, история, схемы инструментов и расход субагентов в неё не входят.
- Фактические счётчики берутся из payload `stop`, только если Cursor их передаёт. Кэш не прибавляется к входу повторно.
- `stop` сохраняет отчёт и HTML без автоматического follow-up. Открытие уже созданной страницы не вызывает модель.
- Текущий `answer-link.cjs` до `stop` может вернуть предыдущую завершённую страницу или индекс сервера. Новая страница появляется после `stop`; точная привязка ссылки внутри текущего незавершённого ответа пока не гарантируется.
- Pending-состояние общее для установки: параллельные чаты могут влиять на оценочную разбивку. История ограничена 200 ходами на чат и индексом 50 чатов.
- Журналы, агрегаты и страницы лежат в `~/.cursor/token-lens/`, отдельно от репозитория. Локальный сервер отдаёт файлы этого каталога, включая JSON; исходники не содержат пользовательскую статистику.

Состав исходников: `.cursor-plugin/`, `hooks/`, `scripts/`, `mcp/`, `rules/`, `commands/`, `skills/`, `extension/`. Тесты вычислений запускаются через `npm test`. Полная работа hooks и интерфейса зависит от версии Cursor и требует проверки в самой IDE.
