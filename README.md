# Token Lens

Прозрачный расход токенов в AI-харнесах: сколько ушло на ответ и что занимало его контекст.

Общая идея — давать доступ к статистике конкретного ответа сразу из чата, без ручного поиска сессии и без нового запроса к модели. Интеграция с каждым харнесом находится в отдельном адаптере.

## Принципы

- Фактические счётчики и оценка по потребителям показываются раздельно.
- Отчёт привязан к конкретному ответу и остаётся доступен после следующих сообщений.
- Кэш и рассуждения учитываются по семантике источника, без двойного подсчёта.
- Недоступные данные обозначаются явно; отсутствующие счётчики не выдумываются.
- Локальные данные обрабатываются локально.

## Адаптеры

| Харнес | Состояние | Реализация |
| --- | --- | --- |
| Codex | Реализован локальный плагин MCP Apps, версия 0.1.3 | [adapters/codex](adapters/codex/) |
| Cursor | Импортирована реализация плагина 0.2.0: hooks, MCP, локальные HTML-отчёты и исходники IDE-расширения | [adapters/cursor](adapters/cursor/) |
| OpenCode | Планируется; адаптер ещё не реализован | Потребуется источник usage OpenCode и его собственная интеграция интерфейса |

Сейчас репозиторий содержит реализации для Codex и Cursor. Проверки и ограничения каждой реализации описаны в её README. Общая библиотека будет выделяться по мере появления реального повторного использования между адаптерами.

## Быстрый старт для Codex

Из корня клонированного репозитория:

```sh
cd adapters/codex
npm ci --ignore-scripts
npm test
codex plugin marketplace add ../..
codex plugin add codex-token-lens@token-lens-local
node scripts/enable-default.cjs
```

Последняя команда включает ссылки «📊 Токены этого ответа» по умолчанию во всех проектах через глобальный `AGENTS.md`. После установки или обновления полностью перезапустите Codex.

Требуются Node.js 22+, npm и Codex с поддержкой локальных плагинов и MCP Apps. Подробности, ограничения и отключение глобального правила — в [README адаптера Codex](adapters/codex/README.md).

## Структура

```text
.agents/plugins/marketplace.json  Локальный каталог плагинов Codex
adapters/codex/                   Исходники, сборка, тесты и инструкции Codex
adapters/cursor/                  Hooks, MCP, HTML-отчёты и расширение Cursor
```

Будущие адаптеры размещаются в `adapters/<harness>/`. Они используют данные и точки расширения своего харнеса; их поддержка не следует автоматически из наличия адаптера Codex.

## Проверки

```sh
cd adapters/codex
npm test
npx playwright install chromium
npm run test:ui
```

Тесты проверяют счётчики и их изоляцию, чтение журналов, установщик глобального правила, совместимость адресов MCP и HTML-панель в Chromium. Проверка установленного плагина в самом харнесе выполняется отдельно.
