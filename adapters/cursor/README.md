# Token Lens для Cursor

Адаптер Token Lens для Cursor: локальная аналитика запроса/ответа, оценка потребителей инструментов, HTML-отчёт и необязательная панель со строкой состояния.

Версия плагина и MCP-сервера — 0.2.0. Исходники IDE-расширения в `extension/` имеют собственную версию 0.1.2. Лицензия этого адаптера — [MIT](LICENSE).

## Состав

- `.cursor-plugin/plugin.json` — манифест локального плагина.
- `hooks/hooks.json` и `scripts/hook.cjs` — обработчики `beforeSubmitPrompt`, `postToolUse`, `stop`.
- `scripts/lib.cjs` — счётчики, оценка UTF-8 байт / 3, агрегаты по чатам.
- `scripts/answer-page.cjs`, `answer-link.cjs`, `serve.cjs` — HTML-страницы ответов и локальный сервер.
- `mcp/` — MCP-инструменты `token_usage_panel` и `read_token_usage`.
- `extension/` — исходники расширения со строкой состояния и командами панели.
- `commands/`, `rules/`, `skills/` — инструкции для Cursor.

## Установка этой реализации

Ожидаемое расположение установленного адаптера:

```text
~/.cursor/plugins/local/cursor-token-lens/
```

Скопируйте содержимое `adapters/cursor` в этот каталог и выполните команды из него:

```sh
npm ci --ignore-scripts
npm test
node scripts/enable-default.cjs
```

Установщик добавляет User MCP в `~/.cursor/mcp.json` и глобальное правило в `~/.cursor/rules/token-lens-analytics.mdc`, затем запускает локальный сервер отчётов. Существующие корректные записи MCP сохраняются. Перед запуском убедитесь, что текущий `mcp.json` является валидным JSON.

После установки перезагрузите окно Cursor / MCP. Корневой `mcp.json.example` — только пример: подключение MCP одновременно из User и Plugin создаст дубликаты.

Необязательная ручная установка IDE-расширения:

```sh
node scripts/install-extension.cjs
```

Этот скрипт копирует расширение в каталог Cursor и обновляет локальный индекс расширений; затем нужен Reload Window. При публикации адаптера установщики не запускались и пользовательские конфигурации не изменялись.

## Отчёты и данные

Ссылки имеют вид `http://127.0.0.1:3847/answers/<generation>.html`. Сервер привязан к loopback; порт можно изменить через `TOKEN_LENS_PORT`.

Рабочие данные находятся отдельно от исходников в `~/.cursor/token-lens/`: журналы usage, текущий ход, агрегаты чатов и HTML-страницы. Эти данные не входят в репозиторий. Сервер отдаёт локальные файлы этого каталога, поэтому сохраняйте доступ к компьютеру и loopback-сервису в пределах доверенной среды.

Фактические счётчики берутся из полей payload `stop`, когда Cursor их предоставляет. Без этих полей счётчики остаются недоступными. Потребители оцениваются по аргументам и результатам tools как UTF-8 байт / 3; это не распределение биллинга.

`stop` может отправлять follow-up с просьбой вывести ссылку. Для отключения этого поведения используйте `TOKEN_LENS_FOLLOWUP=0`. Сам просмотр уже созданной HTML-страницы не требует обращения к модели.

Pending-состояние общее для установки: параллельные чаты могут влиять на оценочную разбивку. Сохранённые агрегаты ограничены 200 ходами на чат и индексом 50 чатов. Сквозная работа hooks и интерфейса зависит от версии Cursor; при переносе выполнены синтаксические проверки и тесты вычислительных функций, без перезапуска рабочей IDE.
