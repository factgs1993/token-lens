# Token Lens

Прозрачный расход токенов в AI-харнесах: сколько ушло на ответ и что занимало его контекст.

Общая идея — давать доступ к статистике конкретного ответа сразу из чата, без ручного поиска сессии и без нового запроса к модели. Интеграция с каждым харнесом находится в отдельном адаптере.

## Принципы

- Фактические счётчики и оценка по потребителям показываются раздельно.
- Отчёт привязан к конкретному ответу и остаётся доступен после следующих сообщений.
- Кэш и рассуждения учитываются по семантике источника, без двойного подсчёта.
- Недоступные данные обозначаются явно; отсутствующие счётчики не выдумываются.
- Локальные данные обрабатываются локально.

## Установка

Нужны **Node.js 22+ и npm**, затем выберите свой харнес. Для клонирования приватного репозитория ваш GitHub-аккаунт должен иметь к нему доступ:

```sh
git clone https://github.com/factgs1993/token-lens.git
cd token-lens
```

Можно скачать ZIP через **Code → Download ZIP** в GitHub, распаковать его и открыть терминал в папке с этим README. Дальнейшие команды в инструкциях начинаются из этой папки.

| Харнес | Как установить | Подробные шаги |
| --- | --- | --- |
| **Codex** | Собрать `adapters/codex`, зарегистрировать локальный каталог плагинов и установить плагин. Включить ссылки после каждого ответа, затем полностью перезапустить Codex. | [Установка, проверка и обновление Codex](adapters/codex/README.md#установка) |
| **Cursor IDE (Windows)** | Скопировать `adapters/cursor` в `~/.cursor/plugins/local/cursor-token-lens`, установить зависимости и запустить `enable-default.cjs`. Он настроит MCP, правило ссылок и автозапуск сервера. Затем Reload Window. Расширение строки состояния устанавливается отдельно по желанию. | [Установка, проверка и обновление Cursor](adapters/cursor/README.md#установка) |
| **OpenCode** | Скопировать `adapters/opencode` в `~/.config/opencode/plugins/opencode-token-lens/`, установить зависимости и по желанию запустить `enable-default.cjs` для ссылок в конце ответа. Полностью перезапустить OpenCode. | [Установка и проверка OpenCode](adapters/opencode/README.md#установка) |

Для Codex вид единственной ссылки задаётся параметром `reportView` в `~/.codex/token-lens/config.json`: `mcp` (по умолчанию) или `browser`. Там же или в интерфейсе **Настройки** можно включить `appendPlanLimits` и `appendContextHeat`; оба параметра по умолчанию выключены. Лимиты общие для аккаунта, индикатор контекста относится к последнему измеренному запросу модели в текущем ходе. Удаление и автоочистка скрывают отчёты только в Token Lens и сохраняют журналы Codex. [Все настройки и пример конца ответа](adapters/codex/README.md#настройка-вида-отчёта).

В Cursor настройка `appendPlanLimits` добавляет дату получения лимитов аккаунта. В OpenCode настройка `appendTokenSummary` добавляет дату снимка и счётчики текущего хода. Обе опции по умолчанию выключены. Даты используют часовой пояс компьютера и сохраняют время исходных данных при повторном использовании снимка.

## Структура

```text
.agents/plugins/marketplace.json  Локальный каталог плагинов Codex
adapters/codex/                   Исходники, сборка, тесты и инструкции Codex
adapters/cursor/                  Hooks, MCP, HTML-отчёты и расширение Cursor
adapters/opencode/                Plugin API V2, HTML-отчёты, TUI, desktop и RPC OpenCode
```

Будущие адаптеры размещаются в `adapters/<harness>/`. Они используют данные и точки расширения своего харнеса; их поддержка не следует автоматически из наличия адаптера Codex.

## Проверки

Каждый блок ниже запускается отдельно из корня репозитория.

```sh
cd adapters/codex
npm ci --ignore-scripts
npm test
npx playwright install chromium
npm run test:ui
```

Тесты проверяют счётчики и их изоляцию, чтение журналов, установщик глобального правила, совместимость адресов MCP и HTML-панель в Chromium. Проверка установленного плагина в самом харнесе выполняется отдельно.

Для Cursor, также из корня репозитория. UI-тест использует Playwright из адаптера Codex:

```powershell
cd adapters/codex
npm ci --ignore-scripts
npx playwright install chromium
cd ../cursor
npm ci --ignore-scripts
npm test
npm run test:ui
```

Для OpenCode, также из корня репозитория:

```sh
cd adapters/opencode
npm ci --ignore-scripts
npm test
```

В PowerShell, если выполнение `npm.ps1` или `npx.ps1` заблокировано, используйте `npm.cmd` и `npx.cmd`.
